# Ручна перевірка Windows — 2026-10-12

Наведені фізичні перевірки не видаються за виконані. Запуск, keychain, один пакет із JPEG/[mic]/[system]/двома питаннями, HTTP429 fallback, MAIN/SIDE/SPEAK, три режими, OCR/UIA, WASM та нативні стилі вже перевірено автоматично. Повні команди/exit/tail — BUILD_LOG.md.

## Перші п'ять перевірок [NEEDS HUMAN CHECK]

1. Запустіть `RELEASE\START_PLUELY.cmd`. Натисніть Shift+\ один раз: чат має стати непрозорим. Перетягніть заголовок до верхніх і нижніх кутів, змініть розмір. Повторіть бінд або Escape — чат стає прозорим і кліки проходять у програму під ним. Перевірте правий Shift. Змініть цей бінд у «Гарячі клавіші», повторіть.
2. У «Налаштування → Вигляд накладеного інтерфейсу» змініть прозорість чату, смуг і кожної кнопки. Перемкніть усі три режими Ctrl+Shift+U. За фоном має бути чітко видно програму, рамку — видно; переливання, якщо ввімкнено, лише на рамці. Перезапустіть — значення й розташування мають зберегтися.
3. Відкрийте браузер/редактор, установіть курсор у його текст. Показ відповіді й натискання Listen/screenshot не повинні забирати фокус. Активуйте чат Ctrl+Shift+I, напишіть питання, поверніться в пасивний режим — фокус має повернутися в попередню програму. Ctrl+\ приховує/показує весь overlay; Ctrl+Shift+R повертає загублені кнопки.
4. Налаштуйте власний brain та незалежний STT. Увімкніть мікрофон і системний звук, відтворіть короткий звук і скажіть фразу. У trace вашого локального API/лічильнику перевірте позначення [mic]/[system], bounded requests і відсутність одночасних AI запитів. Додайте питання під час роботи, зробіть знімок. Text-only brain має отримати OCR/UI/VLM context замість неправильного image payload.
5. Увімкніть системний, Piper або хмарний TTS. Перевірте українську й англійську фрази, pause/resume, stop, перехід між реченнями й повне disable. Підсвічування має приблизно йти за словом. На цьому ПК uk-UA системний голос відсутній; потрібен власний голос/провайдер.

## Захист від захоплення й порядок вікон [NEEDS HUMAN CHECK]

- Максимізоване вікно, Task Manager із «Always on top», borderless відео: оболонка лишається видимою. Exclusive fullscreen може обходити звичайні desktop overlays; зафіксуйте фактичний результат.
- OBS Display Capture, Window Capture, PrintScreen і Win+Shift+S: перевірте кожний метод окремо. Вікна мають affinity `0x11 = WDA_EXCLUDEFROMCAPTURE`; нативний запит це підтвердив. Не припускайте, що всі драйвери/рекордери його поважають.
- Перевірте taskbar/Alt+Tab: службове й shell-вікна не повинні займати taskbar; dashboard — звичайна панель. Кліки поза вузькими смугами/кнопками і всі кліки по пасивному чату мають проходити вниз.

## DPI, монітори, положення [NEEDS HUMAN CHECK]

- Windows масштаб125/150/200%, друга фізична панель ліворуч із від'ємними координатами, інша DPI. Chat рухається вільно; бічні смуги лише по X, top/bottom лише по Y; кнопки вільно.
- Перемістіть кожний елемент, перезапустіть. Від'єднайте/поверніть монітор, застосуйте find/reset. Жодне вікно не повинно остаточно загубитися чи залізти за панель задач.
- Автоматична перевірка на цьому ПК: workarea1536x816, chat900x600 physical; кути (0,0) та (636,216) досягнуто. Візуальний chat480 CSSpx дорівнює viewport; невидимих вертикальних полів немає.

## Ліміти, секрети й провайдери [NEEDS HUMAN CHECK]

- Установіть per-minute1 та глобальний1. Друга дія чекає; індикатор відраховує скидання і автоматично поновлює запит. Перезапустіть до скидання: бюджет має зберегтися. Поверніть потрібні ліміти; 0 = unlimited.
- Власні Google/OpenRouter/OpenAI-compatible/Ollama/LM Studio: перевірте model list, редаговані cURL і supportsImages. Для failing primary перевірте fallback, після cooldown — автоматичне повернення до найвищого рангу. Тестовий localhost429 already passed; реальні API не запускалися без ваших ключів.
- Збережіть новий ключ, перезапустіть. Метадані в profile JSON/localStorage не повинні містити секрет. Не публікуйте ключ або вміст Credential Manager. Міграція старих ключів має лишити помилку видимою, якщо vault недоступний; не стирайте старі дані до успішного readback.
- OCR мовного пакета + довгий UI tree; VLM/full для text-only. Full не має робити повторний vision request для незмінених кадрів.

## Інсталятори / чистий Windows-профіль [NEEDS HUMAN CHECK]

- У новому локальному Windows-профілі встановіть NSIS `Pluely_0.1.9_x64-setup.exe`; перевірте запуск, shortcut, uninstall. Окремо повторіть MSI. Не встановлюйте обидва поверх один одного для порівняння.
- Microsoft Edge WebView2 Runtime має бути доступний. Протестуйте звичайний AppData запуск і portable launcher. На керованому терміналі Codex AppData write був PermissionDenied, тому portable режим перевірено з явним шляхом.
- Підписи Authenticode не налаштовано. Зафіксуйте SmartScreen/installer результат без вимикання захистів Windows.
- MSI payload розпаковано через WiX dark; administrative msiexec exit1603 на доступі до системної Installer-директорії. Прохід майстра й uninstall ще не підтверджені.

Для результатів записуйте ОС/build, конфігурацію моніторів, провайдер/модель без ключів, фактичну поведінку та PASS/FAIL. Невдалий пункт потребує виправлення або конкретного запису BLOCKED.
